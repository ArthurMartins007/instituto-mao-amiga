# Capturas reais do Swagger para a entrega

Salvar aqui capturas da interface `http://localhost:8080/swagger-ui/index.html` depois de executar a API.

- [ ] GET /api/v1/pontos — lista e página.
- [ ] GET /api/v1/pontos/filtro — filtro e paginação.
- [ ] GET /api/v1/pontos/{id} — ponto existente.
- [ ] POST /api/v1/pontos — cadastro 201.
- [ ] PUT /api/v1/pontos/{id} — atualização 200.
- [ ] DELETE /api/v1/pontos/{id} — exclusão 204.
- [ ] POST ou PUT /api/v1/pontos com campo vazio — erro 400.
- [ ] GET /api/v1/pontos/{id} com UUID inexistente — erro 404.
- [ ] GET /api/v1/doacoes/filtro — histórico e filtro.
- [ ] GET /api/v1/doacoes/{id} — doação existente.
- [ ] POST /api/v1/doacoes — cadastro 201.
- [ ] PUT /api/v1/doacoes/{id} — atualização 200.
- [ ] DELETE /api/v1/doacoes/{id} — exclusão 204.
- [ ] POST /api/v1/doacoes com quantidade zero ou tipo vazio — erro 400.
- [ ] GET /api/v1/doacoes/{id} com UUID inexistente — erro 404.

Não enviar telas de exemplo como se fossem respostas reais. Use o Swagger para executar cada chamada e capture a resposta exibida.
